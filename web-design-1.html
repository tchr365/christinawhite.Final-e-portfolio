Web Design #1

Interactive Web Development Project

INTERACTIVE QUIZ

I created this customized 5th-grade math review quiz using template HTML and JavaScript files. I made several changes to the template files to customize the quiz, including adding ten math questions, four answer choices for each, personalized messages for correct answers, and a "Start Over" button. I also learned how to embed an image. I had to do some extra research on some of the changes I wanted to make to the quiz, so I watched several of the suggested videos and found the W3Schools videos the most helpful. I decided to try my hand at my first CSS file, which was another learning curve, but I did it. It’s nothing earth-shattering, but for someone who has never done this before, I’m proud of what I did. In this file, fonts, font sizes, font colors, and background colors for the quiz were coded. I learned so much from this project that I never knew about web development. It was interesting to see how the pieces fit together: HTML builds the structure, JavaScript handles the logic and interactivity, and CSS makes it visually appealing. The actual coding process is definitely time-consuming, and it’s amazing how a single typo can break the entire program. I also learned the hard way exactly why you need to save and test your code in the browser after every single change. I only made that mistake once.
