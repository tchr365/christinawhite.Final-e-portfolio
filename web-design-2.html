Interactive Web Development Projects

CUSTOMIZED DRAG-AND-DROP

I created this customized drag-and-drop rounding-to-the-nearest-100 activity using template HTML and CSS files. I made several changes to the file templates, such as font styles, font colors, and background colors, and also included a self-correcting feature where the number cards turn green if they are sorted correctly or red if they are not. I formatted the containers to be a certain width, added rounded corners, and formatted their position on the webpage. In addition, I added a "Start Over" button at the bottom. I learned that coding requires close attention to detail and precision; otherwise, it will not work. It took me a few hours to complete this drag-and-drop activity, editing and testing it until it looked and worked the way I needed it to. In the process, I have also learned how important it is to run the HTML file in the browser to check appearance and functionality after each edit. I have gained a better understanding of how HTML and CSS work together to create an interactive user experience.

AI DRAG-AND-DROP

I created this customized drag-and-drop rounding-to-the-nearest-100 activity using ChatGPT. After creating the first drag-and-drop activity using the traditional method, I knew exactly how I needed to prompt ChatGPT to create this AI version. It was a long, detailed prompt, but the output was almost exactly what I was looking for on the first generation. I had to prompt it five more times to get it exactly the way I wanted, but the edits were simple ones. The AI method was incredibly easier and much faster than the traditional way. I also preferred the look of the AI version over the one that I created using the traditional method. In the end, the AI approach was my preferred method. It was not difficult building the prompt because I knew exactly what I was looking for in the final product. In addition, this whole process took much less time to create a complete drag-and-drop activity that I was happy with. I learned that an initial detailed prompt can definitely help save time on additional prompting.
